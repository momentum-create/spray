# SPRAY 公式サイト再構築ロードマップ（確定版）

**対象:** [http://www.spray166.com/](http://www.spray166.com/)  
**作成日:** 2026年5月18日  
**根拠:** 実サイトクロール診断 ＋ 戦略的テクニカルレポート（Google ドキュメント PDF）の統合・照合

---

## 1. 目的と成功指標

### 1.1 再構築の目的

| # | 目的 | 現状の阻害要因 |
|---|------|----------------|
| 1 | **実店舗・スケートパークへの来店促進** | HTTP 警告、地図未連携、スマホで読みにくい料金表 |
| 2 | **3 EC チャネルへの安定送客** | HTTP リンク、計測断絶、導線の分散 |
| 3 | **スタッフによる日常更新** | ニュース枠が空、BeTheme/RevSlider の運用負荷 |
| 4 | **専門性・信頼（E-E-A-T）の可視化** | デモテーマ残骸、不適切 URL、alt 流出 |

### 1.2 成功指標（KPI 例）

- 全ページ **HTTPS 200**、証明書エラー **0**
- Core Web Vitals: モバイル **LCP &lt; 2.5s**（目標）
- オーガニック検索: 「旭川 スケートパーク」「旭川 スノーボード ショップ」等の順位・インプレッション（GA4）
- EC 送客: 各モールへのクリック数・CTR（UTM 付与後）
- 問い合わせ: フォーム送信数・`tel:` タップ数
- 運用: スタッフが **週1回以上** ニュース更新可能

## 2. 確定した技術方針

### 2.1 コーポレートサイト

| 項目 | 方針 |
|------|------|
| CMS | **WordPress 継続**（最新安定版へ更新） |
| テーマ | BeTheme + RevSlider **廃止** → ブロックテーマ or 軽量テーマ（子テーマ） |
| 編集 | Gutenberg ＋ **CPT**（news / brand / park 等）＋ ACF 等 |
| サーバー | PHP **8.2+**、Let's Encrypt、**HTTP→HTTPS 301**、**HSTS** |
| セキュリティ | WAF、ログイン保護、`wp-json` 露出の見直し |

### 2.2 外部 EC（変更なし）

| チャネル | URL | 役割 |
|----------|-----|------|
| GMO メイクショップ | `https://www.spray166.shop/` | 自社 EC（在庫・決済はここ） |
| 楽天市場 | `https://www.rakuten.ne.jp/gold/spray/` | モール送客 |
| Yahoo!ショッピング | `https://store.shopping.yahoo.co.jp/spray/` | モール送客 |

**コーポレート側の役割:** 情報発信・信頼構築・**HTTPS の送客リンク＋計測**（カート機能は載せない）

### 2.3 戦略オプション（フェーズ3で意思決定）

**オプション A（標準・推奨の第一案）**  
- ドメイン分離維持: `spray166.com` ＝ 情報、`spray166.shop` ＝ EC  
- GA4 / GTM で送客・コンバージョンを設計（UTM 標準化）

**オプション B（SEO 最大化）**  
- GMO **「WordPress連携オプション」** により、ブログ等を `spray166.shop` 傘下に統合  
- ドメインパワー集約・リファラー一体化を狙う（有料・インフラ複雑）

→ **フェーズ1〜2はオプション A で進行**。オプション B は KPI とコスト見積もり後に Go/No-Go。

## 7. 役割分担（RACI 簡易）

| 領域 | 店舗（SPRAY） | 制作・開発 | インフラ / ホスティング |
|------|---------------|------------|------------------------|
| コンテンツ・写真 | **R** | C | - |
| news 日常更新 | **R** | A（初期トレーニング） | - |
| デザイン・テーマ | C | **R** | - |
| SSL・サーバー | I | C | **R** |
| 301・移行 | I | **R** | C |
| GA4・UTM | C | **R** | - |
| EC リンク・モール | **R**（URL確認） | C | - |

R = 実行責任、A = 承認、C = 相談、I = 情報提供

## 8. リスクと対策

| リスク | 影響 | 対策 |
|--------|------|------|
| SSL 修復遅延 | ローンチ全体が止まる | フェーズ1を最優先・ホスティング契約先と SLA 合意 |
| 301 漏れ | SEO 下落・404 | マッピング表 + 移行後2週間監視 |
| スタッフの更新習慣 | news が空のまま | 週1テンプレ・スマホ投稿手順書（1枚） |
| BeTheme 依存資産 | 再構築コスト増 | フェーズ2で一括脱却、RevSlider スライドは静止画化 |
| GMO 連携オプション | コスト・複雑化 | フェーズ4まで判断延期（オプション A で先行） |
| 証明書・PHP 老朽 | セキュリティ事故 | フェーズ1で OS/パネル更新をセット |

## 9. ローンチ前チェックリスト（抜粋）

### セキュリティ
- [ ] 全ページ HTTPS、証明書警告なし
- [ ] HSTS 有効
- [ ] 管理画面 2FA、デフォルト `admin` ユーザーなし
- [ ] 問い合わせフォーム HTTPS POST

### SEO
- [ ] 301 表の全件テスト済み
- [ ] canonical が HTTPS
- [ ] サイトマップ HTTPS 送信済み
- [ ] 主要ページに title / meta description（日本語・店舗向け）
- [ ] LocalBusiness JSON-LD on `/access/`

### UX
- [ ] モバイルで 3 EC ボタンがタップ可能（44px 以上）
- [ ] パーク料金が読める（HTML 表）
- [ ] Maps / `tel:` 動作
- [ ] alt に「コピー」なし

### 計測
- [ ] GA4 プロパティ接続
- [ ] EC クリックイベント発火確認
- [ ] UTM 付与ルール共有済み

### 運用
- [ ] スタッフが news を1件投稿できる
- [ ] バックアップ自動化
- [ ] 更新マニュアル（簡易版）配布
